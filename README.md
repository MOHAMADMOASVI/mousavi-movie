# موسوی مووی — mousavi-movie

یک وب‌اپ کوچک برای پخش ویدیوهای یک پوشه روی شبکهٔ خانگی: در مرورگر، روی تلویزیون (سازگار با ریموت) و در VLC. سرور فقط با کتابخانهٔ استاندارد پایتون نوشته شده و وابستگی‌ای برای نصب ندارد.

## اجرا

ویدیوها را در پوشهٔ `videos` بگذارید و سرور را اجرا کنید:

```bash
python3 server.py
```

سرور به‌طور پیش‌فرض روی پورت 8000 بالا می‌آید. برای پورت دیگر:

```bash
python3 server.py 9000
```

در macOS می‌توانید روی `start.command` دوبار کلیک کنید. سپس از هر دستگاهی در همان شبکه، آدرس مک و پورت را در مرورگر باز کنید. صفحهٔ `/tv` برای تلویزیون و ریموت طراحی شده است.

چند ویدیوی نمونه در `videos` هست تا برنامه بدون فایل اضافه هم کار کند.

## امکانات

- فهرست ویدیوها با تصویر بندانگشتی و پوستر
- پخش در مرورگر با ادامه از جایی که قطع شده بود
- زیرنویس و فهرست پخش `playlist.m3u` برای VLC
- فرمت‌هایی که مرورگر پخش نمی‌کند (مثل `mkv` و `avi`) همچنان در VLC باز می‌شوند

## ابزارهای اختیاری

- `ffmpeg` و `ffprobe`: برای ساخت تصویر بندانگشتی و خواندن مدت ویدیو. بدون آن‌ها برنامه کار می‌کند ولی این دو قابلیت را ندارد.
- `make_posters.py`: برای هر ویدیو یک پوستر عمودی در پوشهٔ `posters` می‌سازد (به `ffmpeg` و Google Chrome نیاز دارد). برای استفاده از تصویر دلخواه، فایلی هم‌نام ویدیو در `posters` بگذارید.

## برنامهٔ Android TV

پوشهٔ `android-tv` یک برنامهٔ سادهٔ Android TV است که سرور را در شبکه پیدا می‌کند و همان صفحهٔ `/tv` را نشان می‌دهد. ساخت آن Gradle لازم ندارد، ولی JDK و Android SDK (با `platforms;android-34` و `build-tools`) لازم است:

```bash
cd android-tv && ./build.sh
```

خروجی در `android-tv/build/mousavi-movie.apk` ساخته می‌شود. کلید امضا در اولین اجرا به‌صورت محلی ساخته می‌شود و در مخزن نیست.
